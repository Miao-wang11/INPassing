## 本机基本验收步骤

1. 首次克隆配置 docker/.env，设置真实的强管理密码和 JWT 密钥；本机演示才开启 SHUNSHOU_DEMO_SEED=true。
2. Docker Compose 启动四个服务；检查 docker compose ps 和 http://localhost:8080/api/actuator/health。
3. 管理员创建学校校区并审核学生；东校区两位用户完成普通任务与服务定向预约；西校区用户访问被拒绝。
4. 完成一笔待确认订单后发起售后，分别测试管理员驳回与全额模拟退款，检查资金流水与操作日志。
5. 管理后台资金对账页面检验流水；使用 HBuilderX 实际启动移动端并保留录屏。

## 已有库升级顺序

旧库必须备份，按下面顺序一次性执行（不要重跑含 DROP DATABASE 的 backend/runningerrands.sql）：

20261020_campus_scope.sql → 20261020_service_offer_booking.sql → 20261020_order_dispute.sql → 20261020_operations_indexes.sql

不要用 docker compose down -v 清空真实业务数据卷；历史没有校园归属的记录必须人工核实。
